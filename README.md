# Nutcracker Keeper

A phone web app for tracking a Kurt Adler nutcracker collection (plus other brands).

- Everything is saved on the phone (IndexedDB) — no account needed. Use **More → Save backup file** now and then.
- Kurt Adler photos and links come from kurtadler.com.
- Photo matching runs on the phone with an open model (DINOv2-small via transformers.js); `emb.bin` holds the catalog fingerprints.
- Add to the iPhone home screen from Safari: Share → Add to Home Screen.
